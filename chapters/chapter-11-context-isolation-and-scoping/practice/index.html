Practice Bank: Context Isolation and Scoping

Eight short, independent scenarios, each its own fictional pipeline with a deliberate isolation boundary — none of them Vesteroak Regional Appeals Review Board/AppealLine or Calloway County Child Welfare Case Review Network/CaseShield again. Each scenario is a few sentences and one judgment or arithmetic question about this chapter's own new skill: naming an isolation goal, separating opinion from shared fact, budgeting a hand-off contract, and classifying a context bundle with the contamination and starvation probes — not ordinary pipeline scoping, which is Chapter 10's own already-built territory. The point is speed and accuracy across many different isolation boundaries.

starter.py solution.py (reference)

1 Brightfen Regional Utility Outage Response Cooperative Judgment

Isolating a Root-Cause Review Agent from a Dispatch Agent's own classification — does that alone guarantee the shared outage-classification rubric still gets through?

2 Norwick Regional Medical Second-Opinion Network Production-gear

No-isolation vs. scoped-recipe token arithmetic for a Second-Opinion Agent's own budget.

3 Marrenfield Regional Crop Insurance Claims Bureau Judgment

Deleting an initial agent's entire output as isolation — sufficient, if the shared payout schedule goes with it?

4 Coalport Regional Ferry Safety Inspection Authority Production-gear

Curate an inspector's own raw output down to the fields safe to hand off to an independent re-inspection.

5 Sallowbrook Regional Land Trust Conservation Board Judgment

Isolating an Appeals Panel from a Review Committee's own vote — does that guarantee the shared eligibility formula still gets through?

6 Vantree Regional Air Quality Monitoring Network Production-gear

Classify candidate payloads as compliant, contamination-fail, or starvation-fail.

7 Kesterly Regional Public Records Redaction Service Production-gear

A pipeline-wide ledger check across three steps, each with its own budget line.

8 Wolvercote Regional Peer Review Grant Panel Judgment

Two reviewers isolated from each other's own scores — does that mean neither should get the shared funding cap?
