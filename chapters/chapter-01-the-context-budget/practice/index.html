Chapter 1 Practice Bank ~20 min, fast pattern recognition

Practice Bank: The Context Budget

Eight short, independent scenarios, each its own fictional system — none of them Brackwater Home Internet/SignalDesk or Cobalt Home Security/GuardLine again. Each scenario is a few sentences and one judgment question. The point of this bank isn't depth on one system (that's what the exercises did) — it's speed and accuracy across many different systems, the way a real context-engineering review actually feels: a fast parade of "what's going on here, and which ledger line explains it" questions across a whole backlog of features.

Practice standard Eight scenarios. Two are pure judgment calls with no single obvious "gotcha" keyword (Scenario 5 asks whether a described process is already sufficient; Scenario 6 asks you to prioritize between two real but unequal gaps) — these test judgment, not just pattern matching against a line name.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect 8/8.
starter.py solution.py (reference)
Scenario 1

Windermere Legal Services

A client-intake assistant's system prompt has accumulated eleven paragraphs of disclaimers and edge cases over a year of ad hoc edits, none ever removed, eating a fixed, growing share of every request's budget. Which ledger line explains this gap?

Scenario 2

Pinecrest Veterinary Group

A symptom-triage assistant keeps every article its retriever has ever surfaced in a session, including articles about a condition already ruled out. Which line explains this?

Scenario 3

Solmark Payments

A fraud-dispute assistant sends the full, unsummarized transcript every turn; after 40 turns the request exceeds the window and the earliest turns are silently dropped. Which line explains this?

Scenario 4

Thistledown Air Cargo

A shipment-tracking assistant has no persistent memory layer; a customer's stated handling requirement from an earlier session is never re-fetched later. Which line explains this?

Scenario 5 · Judgment

Ravenhollow University Registrar

A team's fix for an unbounded-history problem is to keep sending the full transcript, but only during low-traffic overnight hours "when requests are smaller anyway." Does this actually fix the budget problem, or does a real gap remain?

Scenario 6 · Judgment

Copperfield Home Appliances

Two real, unequal gaps, only one fixable before next week's launch: (a) no eviction policy on grounding context, or (b) the system prompt uses British spelling in two places while the rest of the product uses American spelling. Which is the higher-priority fix?

Scenario 7 · Production-gear

Marrowgate Public Library

A research-assistant team has budget for one investment. Which of four candidates — a bigger model, a re-ranking/eviction step for stale retrieved articles, a faster database, or a prettier chat UI — most directly builds Grounding Context discipline?

Scenario 8 · Production-gear

Fenwick Outdoor Adventures

A trip-planning assistant's team sends the full transcript every turn with no summarization, and never re-fetches a customer's stated gear list from account records on later turns — "the model just carries it in memory." Name both ledger lines most directly missing.
