Module 4 Project — L3 Independent ~75 min

Project: Build Quartzfield's BriefLine Retrieval Integration + Source Assembly Pipeline

Quartzfield Regional Public Defender Consortium's fictional pre-hearing brief assistant, BriefLine, prepares a sentencing brief in two parts. This is Module 4's closing lab, drawing on both chapters this module built — Chapter 7's Source Assembly Recipe and Chapter 8's own Retrieval Integration Recipe — per the curriculum map's own paired Module 4 labs. You design both halves at once: turning a retriever's raw ranked output into one well-formed source (Chapter 8's skill), then combining that source with three others for the same request and resolving a genuine contradiction between two of them (Chapter 7's skill).

A note on this project's tier This is the curriculum map's own literal L3 Independent tier project — unlike Module 3's own project, which fell in a gap the ladder never assigned, this one lands exactly where the four-tier ladder says it should (L1 after Ch. 2, L2 after Ch. 4, L3 after Ch. 8, L4 the Ch. 13 capstone). "Independent" means no scaffold: starter.py gives you the full spec and data, but no partially-filled template and no step-by-step hints beyond that.
How to run it Download starter.py, fill in your Part 1 (retrieval integration) and Part 2 (source assembly) choices and both write-ups, then run python3 starter.py. Most of this project's self-check is fully mechanical — it verifies your Part 1 relevance-floor, boundary-safe-fit, stitching, and provenance choices, and separately verifies your Part 2 contradiction detection, authority-based resolution, and budget fit. Compare against solution.py, then self-grade against RUBRIC.md.
starter.py solution.py (reference) RUBRIC.md README.md

What you're given

Five ranked, scored retrieval chunks (a 0.55 relevance floor and a 380-token budget); four candidate sources for the assembled window, including your own Part 1 output, with a genuine contradiction between two of them about whether a sentencing departure exception currently applies; a fixed authority ranking and a 500-token window budget.

What you produce

A valid relevance-floor survivor set, a boundary-safe budget fit that never truncates a chunk mid-sentence, correct stitching of consecutive same-document chunks, complete provenance for every kept chunk; a correct contradiction detection and authority-based resolution between two disagreeing sources, a correct retained-source set, and a budget-fit confirmation; and two defended write-ups, one per part.

Passing bar

22/28 (about 80%) or higher on RUBRIC.md's seven criteria, with no single criterion scoring 0. solution.py is one complete, valid reference design scoring a full 28/28 — not the only correct design, since both write-ups are intentionally open.

Module 4, complete This project closes Module 4 (Chapters 7-8) in full. Chapter 9, opening Module 5, moves to context engineering for agentic and tool-use systems.
