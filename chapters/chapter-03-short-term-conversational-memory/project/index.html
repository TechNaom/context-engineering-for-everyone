Chapter 3 Project · L1 Guided ~45 min

Project: Design Wrayland's Recurring Counseling Check-In Memory Policy

Wrayland Behavioral Health Group's fictional patient-messaging assistant, SupportLine, already has a correctly allocated 7,500-token Line 3 budget for its "Recurring Counseling Check-In" request type. You're given the real spec — 16 real turns with token counts, a fixed running-summary size, and 6 candidate facts tagged by category. Your task: choose which facts to pin, size a verbatim window that fits the budget, and defend both choices.

Why this project, not another allocation task Chapter 1's project tested diagnosis; Chapter 2's project tested allocation. This chapter's own skill is different again: given a budget that's already correctly sized, can you design the real eviction/compression policy that keeps a long conversation inside it — the exact policy layer this chapter's own hook, Emberlynn Transit Cooperative's RouteLine, never built.
How to run it Download starter.py, fill in your pin choices, verbatim window, and both write-ups, then run python3 starter.py. Most of this project's self-check is fully mechanical — it verifies your required/forbidden pin choices and that your full package fits the given budget. Compare against solution.py, then self-grade against RUBRIC.md.
starter.py solution.py (reference) RUBRIC.md README.md

What you're given

A 7,500-token Line 3 budget, a fixed 1,200-token running-summary size, 16 real turns with token counts, and 6 candidate facts each tagged safety_critical, clinical_change, small_talk, or administrative.

What you produce

A valid set of pinned facts (every safety_critical/clinical_change fact pinned, no small_talk fact pinned), a verbatim window sized to fit the budget alongside your pins and the fixed summary, a defended policy justification, and a follow-up plan naming what covers any turn outside your window.

Passing bar

16/20 (80%) or higher on RUBRIC.md's five criteria, with no single criterion scoring 0. solution.py is one complete, valid reference policy scoring a full 20/20 — not the only correct design, since the two administrative facts' pin status is intentionally open.
