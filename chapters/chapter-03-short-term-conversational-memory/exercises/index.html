Chapter 3 Exercises ~45 min, hands-on

Exercises: Short-Term Conversational Memory

These exercises use a second scenario, deliberately different from the lesson's Emberlynn Transit Cooperative/RouteLine hook: Quarrowstead Legal Aid Partners, a fictional legal aid organization. Its internal caseworker assistant, DocketLine, holds long case conversations on a model with a correctly allocated 6,000-token Line 3 budget. Building the real eviction/compression policy that keeps that budget honest is the point; the budget number itself is already given.

Exercise standard Eight tasks total. Six are marked production-gear — running-total arithmetic, verbatim window sizing, pin/no-pin classification, compression trigger checks, package validation, and a naive-vs-hybrid regression gate, not just concept recall.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect total.
starter.py solution.py (reference)

1 Match scenarios to short-term memory policies

Decide which of three DocketLine scenarios need a real eviction/compression policy at all, and which genuinely don't.

2 Order the Short-Term Memory Policy Recipe

Put the lesson's six policy steps in the correct sequence, from starting at the allocated budget to worst-case validation.

3 Production-gear Running totals, first turn over budget

Compute cumulative token totals across a growing conversation and find the first turn that exceeds the 6,000-token budget.

4 Production-gear Verbatim window sizing

Compute how many recent turns can stay raw once pinned-fact and summary reserves are subtracted from the budget.

5 Production-gear Pin/no-pin classification

Decide which facts from a real DocketLine case conversation are load-bearing enough to pin.

6 Production-gear Compression trigger check

Find the turn where compression should start, deliberately ahead of the hard budget limit.

7 Production-gear Build and validate the final memory package

Verify a package of pinned facts, summary, and verbatim turns actually fits inside the Line 3 budget.

8 Production-gear Naive-vs-hybrid regression gate

Confirm a pinned fact that a naive FIFO policy would drop survives under the hybrid policy — the exact gap the lesson's hook fell into.
