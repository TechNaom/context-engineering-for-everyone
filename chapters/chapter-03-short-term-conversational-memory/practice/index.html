Practice Bank: Short-Term Conversational Memory

Eight short, independent scenarios, each its own fictional system — none of them Emberlynn Transit Cooperative/RouteLine or Quarrowstead Legal Aid Partners/DocketLine again. Each scenario asks one judgment or arithmetic question about keeping conversation history inside an already-allocated Line 3 budget, not deriving the budget itself.

Practice standard Four judgment-call scenarios, four production-gear arithmetic scenarios, across eight fresh fictional organizations.
starter.py solution.py (reference)

1 Larkmoth Outdoor Retail Judgment

Does raising Line 3's token budget alone fix a forgotten early fact, without a real policy?

2 Feldspar Municipal Water Utility Production-gear

Verbatim window sizing arithmetic after pinned-fact and summary reserves are subtracted.

3 Pemberglen Veterinary Partners Judgment

Should a pinned-fact reserve be allowed to grow without any size limit?

4 Sootmarsh Freight Cooperative Production-gear

Find the turn where a compression trigger threshold is first reached.

5 Glennoak Wealth Advisors Judgment

Is continuous, from-turn-1 summarization a good default?

6 Tarnwick Community College Production-gear

A pin/no-pin call on a single safety/eligibility-relevant disclosure.

7 Hushfield Telehealth Network Production-gear

Does a built short-term memory package fit inside its Line 3 budget?

8 Vallowmere Grocery Cooperative Judgment

Does adding a compression policy remove the need for worst-case validation?
