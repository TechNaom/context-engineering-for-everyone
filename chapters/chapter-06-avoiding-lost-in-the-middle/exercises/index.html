Chapter 6 Exercises ~45 min, hands-on

Exercises: Avoiding Lost-in-the-Middle

These exercises use a second scenario, deliberately different from the lesson's Marchside Regional Trauma Network/VitalsLine hook: Calverton Public Defender's Office, a fictional public defender's office. Its case-file review assistant, DocketLine, handles case files that can run long before the attorney's actual question gets asked. Chapters 1-5's own recipes are already given here — every fact is present, unmodified, and within budget. Building the real ordering mechanics that decide where each fact goes is the point.

Exercise standard Eight tasks total. Six are marked production-gear — position- percentile arithmetic, weight classification, a positional probe, anchor classification, a regression gate, and a retest decision, not just concept recall.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect total.
starter.py solution.py (reference)

1 Match scenarios to ordering approaches

Decide which of three DocketLine scenarios use arrival order, naive top-loading, or the full weight-ranked, both-anchors pipeline.

2 Order the Context Ordering Recipe

Put the lesson's five recipe steps in the correct sequence, from ranking by weight to testing position directly.

3 Production-gear Position-percentile arithmetic

Compute a fact's midpoint percentile in a 3,200-token window and whether it falls in the high-risk middle band.

4 Production-gear Load-bearing weight classification

Decide which case-file details carry enough weight to require an anchor position.

5 Production-gear Positional probe: anchor-required facts

Find which anchor-required facts are missing from a produced window's actual placements, and whether the probe passes.

6 Production-gear Query/instruction anchor classification

Classify six content types by whether they belong at the end anchor nearest generation.

7 Production-gear Arrival-order-vs-weight-ranked regression gate

Confirm a load-bearing detail arrival order would bury is correctly surfaced by weight-ranked placement.

8 Production-gear Retest/escalation decision

For three positional-probe outcomes, decide whether to ship or retest/reposition.
